# Migration guides

Each guide documents the **consumer action** a release requires, newest first. A release with no
required action has no guide here.

| Version | Guide                                                                                     |
| ------- | ----------------------------------------------------------------------------------------- |
| v2.3.0  | [Upgrading to v2.3.0](v2.3.0.md): RFC conformance, per-token JWE keys, Ed25519 and ML-DSA |
| v2.2.0  | [Upgrading to v2.2.0](v2.2.0.md): custom payloads can no longer set registered members    |
| v2.0.0  | [Upgrading to v2.0.0](v2.0.0.md): security hardening and API modernization (breaking)     |
